# Telegram Custom Bot

Fully customizable Telegram bot with admin panel.

## Features
- Editable welcome text & photo
- Custom buttons (text/photo/URL)
- Button name & action edit
- Force join channels
- Broadcast

## Setup
1. Clone repo
2. `pip install -r requirements.txt`
3. Copy `.env.example` to `.env` and fill values
4. `python bot.py`

## Admin
Send `/admin` to bot (only ADMIN_ID can use).
